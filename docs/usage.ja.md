タグの入力・補完・タグパネル・検索の基本操作は、[READMEの「はじめに」](../README.ja.md#quick-start)を参照してください。このガイドでは、入力規則・認識範囲・共通とノートごとの外観設定・タグの概要・パネル操作・本文内巡回・検索上の注意点を説明します。

<a id="input-rules"></a>

## 入力規則

- ローカルタグには `##topic`、階層には `##people/Alex/work` のように `/` を使います。`## Heading` はMarkdownの見出しです。
- タグ名は大文字・小文字を区別し、`##people/Zoë` のようなUnicodeの名前にも対応します。
- 空白・改行・そのほかのタグ終端文字でタグが終了します。`##` だけでも補完は始まりますが、完成したタグとは扱いません。
- 数字だけ、または数字と `/` だけの名前は通常のテキストとして扱います。先頭・末尾の `/` や連続した `/` は空の階層を作るため無効です。

<a id="recognition-limits"></a>

## 認識範囲

- インラインコード・コードブロック・YAML frontmatter・リンクや画像・URL・HTML・`\##example` のようなエスケープされた表記にあるタグは対象外です。
- コールアウトのタイトル・本文と、表のセル内でも、同じ除外条件でローカルタグを使えます。
- Obsidianの `%% comments %%` 内のタグは補完とタグパネルに含まれますが、Reading Viewには表示されません。

<a id="completion-settings"></a>

## 補完設定

**Settings → Local Tags** を開き、**Completion matching** を選びます。既定の **Substring match** は、入力した文字列を含むタグ名を検索する部分一致です。**Prefix match** は、階層タグ名全体の先頭を含め、入力した文字列で始まる名前を検索する前方一致です。

**Case-sensitive completion** は、既存のインストールも含めて既定では無効です。有効にすると、大文字と小文字を区別して照合します。候補の表示と挿入では元の綴りを保ち、タグの同一性の判定は常に大文字・小文字を区別します。

補完候補は完全一致・前方一致・そのほかの部分一致の順で、現在のファイルから最大10件を表示します。

<a id="appearance-settings"></a>

## 外観設定

**Settings → Local Tags** を開きます。共通の設定はSource mode、Live Preview、Reading Viewに適用されます。

| 設定ラベル                 | 意味                                                                            |
| -------------------------- | ------------------------------------------------------------------------------- |
| Local tag text color       | 有効なローカルタグの文字色を設定します。                                        |
| Local tag background color | タグの背景色を設定します。                                                      |
| Local tag bold             | 既定の書式に従うか、太字を有効または無効にします。                              |
| Local tag underline        | 既定の書式に従うか、下線を有効または無効にします。                              |
| Local tag italic           | 既定の書式に従うか、斜体を有効または無効にします。                              |
| Local tag vertical padding | 上下の余白を−5〜+5 pxの範囲で0.25 px刻みに調整します。0で既定の余白に戻ります。 |

**Reset to theme** は色の上書きを解除します。太字・下線・斜体には、**Follow default**、**Enabled**、**Disabled** から選びます。

**Hide local tag prefix when not editing** は既定では無効です。有効にすると、Reading Viewと、Live Previewで編集中ではない有効なタグの `##` を隠します。タグ内にカーソルを移すか、タグを選択すると接頭辞が表示されます。Source modeでは常に `##` を表示し、Markdownのソースは変更しません。

<a id="per-note-decoration"></a>

## ノートごとの装飾

<a id="configuration-format"></a>

### 設定の書式

本文の最上位に、テキストが正確に `local-tags-config` であるMarkdown見出しを置き、その下にタグ定義を1つの箇条書きリストとして記述します。見出しのレベルは問いません。セクションは、同じか上位のレベルの次の見出し、またはノートの末尾で終わります。

```md
## local-tags-config

- ##project
  - text-color: \#ffffff
  - background-color: \#174266
  - border-color: \#5da9e9
  - bold: on
  - underline: off
  - italic:
- ##project/review
  - background-color: \#49345c
  - underline: on

## Notes

Discuss ##project and ##project/review here.
```

各タグには、次の6つの設定を任意で指定できます。表の順序は、**Add missing settings** と **Remove empty settings** が使う並び順です。

| 設定               | 指定できる値                        |
| ------------------ | ----------------------------------- |
| `text-color`       | `#ffffff` のような6桁の16進数の色。 |
| `background-color` | `#174266` のような6桁の16進数の色。 |
| `border-color`     | `#5da9e9` のような6桁の16進数の色。 |
| `bold`             | `on` または `off`。                 |
| `underline`        | `on` または `off`。                 |
| `italic`           | `on` または `off`。                 |

色には `#RRGGBB` と `\#RRGGBB` のどちらも使えます。色の編集操作では、色の値がObsidian標準のタグにならないよう、エスケープした書式で書き込みます。強調設定には小文字の `on` と `off` を使ってください。

従来の `local-tags` というセクション名や、`style` リスト項目の下に設定をまとめた書式にも対応します。設定セクションは1つ、各タグの定義も1つにしてください。1つの定義内では、属性を直接記述する書式と `style` グループのどちらかを使います。

<a id="inheritance-and-errors"></a>

### 継承とエラー

装飾は設定項目ごとに解決します。共通の外観設定とテーマの既定値を基に、設定がある親タグを上位から順に適用し、最後にタグ自身の値を適用します。結果は、現在のノートのSource mode、Live Preview、Reading View、タグパネルに反映されます。

設定項目がない場合、`italic:` のように値が空の場合、または属性を持たないタグ定義の場合は、親タグの値を継承します。最上位のタグでは共通設定を使います。空の値は有効です。明示的な `off` は、継承した `on` を上書きします。

例の `##project/review` は、`##project` から文字色・枠線色・太字を継承し、自身の背景色・下線の設定を適用します。斜体は共通設定またはテーマに従います。

`text-color: red` や `bold: yes` のような空ではない不正な値は、パネルにエラーとして表示されます。タグ自体は有効なままで、ほかの有効な設定も適用されます。不正な設定項目は、親タグまたは共通設定を継承します。色の編集など、設定を書き込む操作を行う前にエラーを修正してください。

定義の重複・属性の重複・設定見出しの重複・複数の独立した最上位リストに分かれた定義などの構造エラーも、設定の書き込みを妨げます。修正中は、直前の有効な装飾が残ることがあります。不明な項目は警告の対象となり、元のテキストを保持します。

ノート内での編集や外部からの変更に応じて、設定の変更が反映されます。

<a id="tag-panel-actions"></a>

### タグパネルの操作

**Open tag panel** を実行します。タグ一覧の上に、クリックとShift+クリックの操作案内が表示されます。**Settings, actions and messages** を展開してください。その見出しには **Errors** と現在のエラー件数が表示され、新しいエラーが報告されると領域が開きます。分かる場合は、メッセージに対象の行とタグを表示します。

**Target** は、エディタのキャレットが設定ブロック内にある場合に、そのタグを表示します。それ以外の位置では **All tags** を表示します。Reading Viewでも対象は **All tags** です。この対象指定は **Random decoration** に使われます。

編集モードで **Random decoration** を実行するときは、カーソルを1つにしてください。複数カーソルがある場合は、対象が **All tags** であっても操作を受け付けません。

| ボタン                     | 動作                                                                                                                                                                                                                 |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Add missing settings**   | 認識済みのローカルタグに定義がなければ追加し、すべての定義へ不足する属性を空の値で追加します。必要に応じて設定セクションを作成します。既存の値を保ち、属性を上の表の順序に並べます。                                 |
| **Remove empty settings**  | 既知の属性のうち値が空のものを除去し、残った属性を上の表の順序に並べます。属性がなくなったものも含めてタグ定義を保ち、空ではない値や付随する内容も保持します。                                                       |
| **Random decoration**      | 編集モードでは、1つのキャレットが含まれる設定ブロックのタグをランダムに装飾します。**All tags** では、最上位のタグに色を生成して子孫タグへ継承させます。Reading Viewでは、このノート全体を対象とする操作になります。 |
| **Sort settings**          | 大文字・小文字を区別したタグ名の順でタグ定義をソートし、各定義内の内容は一緒に保持します。                                                                                                                           |
| **Expand to tag headings** | Source modeまたはLive Previewで設定のタグ項目を表示し、属性リストを折りたたみます。エディタの折りたたみ状態を変更する操作です。                                                                                      |

たとえば、**Remove empty settings** は次の設定を変更します。

```md
- ##tag1
  - bold: on
  - italic:
- ##tag2
  - bold:
  - italic:
```

変更後も、両方のタグ定義が残ります。

```md
- ##tag1
  - bold: on
- ##tag2
```

ランダム装飾では、文字色・背景色・枠線色に、ビビッドな補色の固定パレットを使います。既存の色を置き換えることがあります。太字・下線・斜体は現在の値を保ちます。`.text-color: \#ffffff` のように属性名の先頭へ `.` を付けると、ランダム装飾時にその値を保持します。`.style` グループは、装飾の適用を続けながら、配下のすべての属性をランダム装飾から除外します。

<a id="color-swatches"></a>

### カラースウォッチ

Source modeまたはLive Previewで、設定内の有効な色の横にあるカラースウォッチをクリックします。6桁の16進数の色を入力するか、色相・彩度・明度のスライダーを調整し、**Apply** を選びます。**Cancel** またはEscで閉じます。編集中のテキストを保護するため、カラーピッカーが開いている間にノートが変わると、更新をキャンセルします。

<a id="tag-descriptions"></a>

## タグの概要

ノートの `local-tags-config` セクションで、完全なタグ名と同じ宣言行の後ろに概要を書きます。

```md
## local-tags-config

- ##project Work owned by this project
- ##project/review Review tasks for this project
```

概要は、現在のノート内で、大文字・小文字まで正確に一致するタグ名に対応します。子タグごとに別の概要を追加してください。概要に含まれるのは宣言行のテキストだけです。ObsidianとHTMLのコメントを除去し、前後の空白を取り除きます。残った概要にあるMarkdownやHTMLは、装飾せず通常のテキストとして表示します。

概要は、一致する各補完候補の横に表示されます。Enterで挿入するのはタグ名と末尾の空白だけです。Source mode、Live Preview、Reading View、タグパネルのタグにポインターを合わせると、少し待ってから概要が表示されます。キーボードでパネルのタグへフォーカスを移すと、すぐに表示されます。Escまたはポインターの移動で閉じます。

ノートの変更に応じて概要を更新します。装飾の値が不正な場合はエラーが報告されることがありますが、概要は引き続き表示できます。定義が重複すると、そのタグの概要は表示されません。設定見出しが複数ある場合や定義リストが分かれている場合は、構造が修正されるまで、すべての概要を表示しません。

<a id="tag-panel-search"></a>

## タグパネル内の検索

**Open tag panel** を実行し、**Search tags** に入力すると、現在のノートのタグ一覧がすぐに絞り込まれます。完全な階層タグ名と、正確に一致するタグに付いた[概要](#tag-descriptions)を部分一致で検索します。英語の照合は大文字・小文字を区別せず、日本語のテキストにも対応します。タグの同一性の判定と補完設定は変更しません。

**Tag name** と **Summary** のチェックボックスで検索対象を選びます。最初は両方が有効で、どちらかに一致すれば表示します。検索文字列を入力したまま両方を無効にすると、一致するタグは表示されません。検索文字列を消すか、空白だけにすると一覧全体に戻ります。前後の空白は無視します。

一致した子タグへの階層が分かるよう、上位タグも表示します。上位タグの概要が一致しても、関係のない子タグは含めません。概要は正確に一致するタグのもので、検索時には上位タグから継承しません。

一覧が更新されても、入力欄とチェックボックスは同じ場所に残ります。ノートを切り替えても現在の検索文字列と検索対象の選択を保ち、それぞれのノートのタグと概要を使います。この一時的な選択は、パネルを開き直すとリセットされます。概要を編集すると検索結果も更新されます。一致するものがなければ **No matching tags** を表示します。

検索欄・チェックボックス・一致なしのメッセージは、Obsidianの言語が日本語なら日本語、それ以外なら英語で表示されます。絞り込まれたタグをクリックすると、従来どおりObsidianの検索を開きます。Shift+クリックによる本文内巡回も使えます。パネルの絞り込みで、ノートの内容やObsidianの検索クエリは変更しません。

<a id="in-note-navigation"></a>

## 本文内巡回

Ctrl・Command・Altを押さずに、パネルのタグをShift+左クリックすると、現在のノート内で最初に出現する箇所へスクロールします。繰り返すとソース内の順序で次の出現箇所へ進み、最後の次は最初に戻ります。親タグは子孫タグにも一致するため、`##people` には `##people/Alex` も含まれます。

Source mode、Live Preview、Reading Viewでは、一致した行をハイライトし、タグを枠で囲みます。Source modeとLive Previewでは、エディタのカーソルと選択範囲を保ちます。接頭辞を隠す設定が有効な場合は、Live Previewの編集中ではないタグの `##` も隠したまま巡回します。折りたたまれた範囲は、一致箇所が見えるよう展開します。

Reading Viewの入れ子リストでは、一致した表示行をハイライトします。Reading Viewと、Live Previewで描画された表では、行のハイライトを一致したセル内に収めます。Reading Viewでは、`%% comments %%` 内に隠れたタグを飛ばします。表示できる出現箇所がない場合は、編集モードでノートを確認するよう通知します。

ノートの編集、対象ファイル・Markdownペイン・表示モードの変更でハイライトを消し、巡回位置をリセットします。別のタグを選ぶと、そのタグの最初の出現箇所から始まります。プラグインを無効にした場合もハイライトを消します。

<a id="search-caveats"></a>

## 検索上の注意点

パネルのタグをクリックすると、既存のObsidian検索クエリを、現在のファイルとタグを対象とするテキスト検索へ置き換えます。検索結果には、コードブロックなど、タグの認識対象外にあるテキストが含まれることがあります。
